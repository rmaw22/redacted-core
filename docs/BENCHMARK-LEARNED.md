# Learned secrets at scale

Median scrub time of the clean corpus, repeated to each size, with the default tiers plus `N` learned entries. Generated by `learned_scale_benchmark` in `crates/redacted-core/src/scrub/learned_benchmark.rs`; numbers are from one machine and move between runs.

- Exact entries: once any is learned, every token is peeled into candidates, and each candidate whose byte length equals a learned `len` is hashed. Cost follows the number of distinct lengths, not of entries. These entries span 32 lengths, so from N = 32 on they add no more cost.
- Shapes: one regex per entry, each starting with a literal prefix the regex engine searches for directly.
